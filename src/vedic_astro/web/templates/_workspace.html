Hora rules & calculation

The first hora starts at sunrise with the weekday’s ruling planet. Repeat Saturn → Jupiter → Mars → Sun → Venus → Mercury → Moon, starting from that ruler.

Day hora duration = (sunset − sunrise) ÷ 12. Night hora duration = (next sunrise − sunset) ÷ 12. For a birth before sunrise, the sequence starts from the previous day’s sunrise.

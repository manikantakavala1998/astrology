# Vimshopaka Bala

The app calculates all four schemes for the seven classical planets using
the same natal ephemeris and divisional signs shown in Divisional Charts.
Each scheme's weights sum to twenty.

Contribution = weight × Varga Viswa points ÷ 20. The relationship points
are own 20, great friend 18, friend 15, neutral 10, enemy 7, great enemy 5.
The existing Panchadha relationship calculation combines natural friendship
with temporal friendship determined from D1, and is retained for all schemes.
There is no additional exaltation/debilitation override in this score.

Weights and the proportional formula were verified against the translated
[BPHS chapter 7, verses 17–27](https://divyachadhava.com/en/sanatan-sahitya/bphs-chapter-7-divisional-considerations).
The fractional weights in verses 20–25 are preserved. Some OCR copies omit
the halves and consequently give scheme totals below twenty.

The six/seven-chart calculations and reading bands remain unchanged.

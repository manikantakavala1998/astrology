# Birth hora

The Panchanga report and the birth-chart summary show the planetary hora active at birth. The full report includes its ruler, position in the 24-hora sequence, day/night position, local start and end, duration, and expandable calculation rules.

The first hora begins at local sunrise with the weekday ruler. Continue the repeating sequence Saturn → Jupiter → Mars → Sun → Venus → Mercury → Moon from that planet. Daylight is divided into 12 equal intervals; sunset to the next sunrise is divided separately into 12. These durations can differ from 60 minutes. Before sunrise, use the previous sunrise's local weekday. The civil-calendar Vara remains separate.

The calculation uses the app's existing solar-event ephemeris. Boundaries include the start and exclude the end. All displayed times use the birth input's UTC offset, regardless of browser timezone. Panchanga, Hora Bala and the Bala calculation trace share the same interval selection.

For 4 September 1998 at 00:03, coordinates 17.00517° N / 81.77784° E and UTC+05:30: Mercury rules hora 19 (night hora 7), starting 00:02:19 and ending 01:00:10. The sequence begins at Thursday's sunrise with Jupiter.
